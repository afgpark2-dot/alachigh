# آلاچیق

پیام‌رسان ایرانی با قابلیت‌های اصلی تلگرام (نسخه ۲)

یک پیام‌رسان کامل با نام **آلاچیق** و قابلیت‌های اصلی تلگرام:

## قابلیت‌ها

| قابلیت | وضعیت |
|--------|--------|
| چت متنی لحظه‌ای | ✅ |
| گروه‌ها و کانال‌ها | ✅ |
| ساخت گروه جدید | ✅ |
| نشانگر تایپ | ✅ |
| لیست آنلاین | ✅ |
| **تماس صوتی گروهی** | ✅ |
| **تماس تصویری گروهی** | ✅ |
| قطع/وصل میکروفون و دوربین | ✅ |
| آپلود فایل / عکس / ویدیو / صدا | ✅ |
| ریپلای (پاسخ به پیام) | ✅ |
| ری‌اکشن (ایموجی روی پیام) | ✅ |
| حذف پیام | ✅ |
| جستجو در پیام‌ها | ✅ |
| ذخیره‌سازی پایدار (SQLite) | ✅ |
| رابط کاربری فارسی و راست‌چین | ✅ |
| تم تاریک شبیه تلگرام | ✅ |

## تکنولوژی

- **بک‌اند**: Node.js + Express + Socket.IO + better-sqlite3 + Multer
- **فرانت‌اند**: React 18 + Vite + Lucide Icons
- **تماس**: WebRTC (STUN)
- **دیتابیس**: SQLite

## نصب و اجرا

### روش سریع

```bash
# سرور
cd server
npm install
npm start

# کلاینت (ترمینال جدید)
cd client
npm install
npm run dev
```

بعد برو به: **http://localhost:5173**

چند پنجره مرورگر باز کن، با اسم‌های مختلف وارد شو و تست کن.

### نیازمندی‌ها

- Node.js 18+
- برای تماس: مرورگر مدرن + دسترسی به میکروفون/دوربین

## محدودیت‌های فعلی

- تماس‌ها به صورت mesh هستند (برای ۲–۵ نفر مناسب). برای گروه‌های بزرگ‌تر باید از LiveKit یا mediasoup استفاده شود.
- احراز هویت ساده است (فقط نام کاربری).
- رمزنگاری انتها به انتها (E2E) وجود ندارد.
- نوتیفیکیشن پوش هنوز اضافه نشده.

## مرحله‌های بعدی پیشنهادی

1. اتصال LiveKit برای تماس گروهی واقعی
2. احراز هویت با شماره تلفن / OTP
3. رمزنگاری E2E
4. اپلیکیشن موبایل (React Native)
5. استیکر و ربات
